# Bug Reports

Create one file per confirmed issue using `bug-report-template.md`.

File name format:

```text
BR-001-short-description.md
```

Store screenshots in `screenshots/` and link them using a relative path:

```markdown
![Actual result](screenshots/BR-001-actual-result.png)
```

Only confirmed defects belong in this directory. Expected behaviour must be based on a requirement, product documentation, or agreed test case.
